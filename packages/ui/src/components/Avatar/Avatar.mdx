# Avatar

**วัตถุประสงค์:** วงกลมเล็กแสดงรูปของบุคคล หรืออักษรย่อชื่อเมื่อไม่มีรูป เพื่อให้จำได้ทันทีว่าใครเป็นใคร

## ควรใช้เมื่อ

- ข้างชื่อบุคคล ในรายการ ความคิดเห็น ข้อความ และส่วนหัวของบัญชี
- อยู่เดี่ยว ๆ เมื่อพื้นที่จำกัดและบริบทบอกชัดว่าเป็นใคร เช่น ผู้ใช้ที่เข้าสู่ระบบในส่วนหัว
- กลุ่มคนในบัญชีหรือโปรเจกต์แบบซ้อนกัน พร้อม "+N" สำหรับคนที่เหลือ

## ไม่ควรใช้เมื่อ

| แทนที่จะใช้ avatar กับ… | ให้ใช้ |
| ----------------------- | ------ |
| บริษัท ทีม หรือแอป | avatar สี่เหลี่ยม TODO: ยังไม่มีรูปสี่เหลี่ยม ใช้ `className` แทนได้ ตาม story `ClassNameOverride` |
| สถานะหรือจำนวนอย่างเดียว | **Badge** |
| รูปโปรไฟล์ขนาดใหญ่ | รูปภาพ Avatar ใหญ่สุด 40px |
| วิธีเดียวที่ใช้แยกคน โดยไม่มีชื่อที่ไหนเลย | แสดงชื่อด้วย ใบหน้าและอักษรย่ออย่างเดียวแยกยาก |

## การเขียนชื่อและอักษรย่อ

- **ตั้งชื่อให้ avatar ไม่ใช่ให้รูป** ใช้ชื่อบุคคล เช่น "Ana Lima" อย่าเขียน "Avatar of" หรือ "Photo of"
- **อักษรย่อ:** หนึ่งหรือสองตัว อักษรแรกของชื่อและนามสกุล เช่น "AL" แหล่งอ้างอิงเห็นต่างกันเรื่องชื่อคำเดียว Fluent ใช้หนึ่งตัว IBM Carbon ใช้สองตัวแรก TODO: เลือกกฎเดียว
- **ชื่อที่ไม่เหมาะกับอักษรย่อ** เช่น ชื่อภาษาจีน ญี่ปุ่น เกาหลี หรืออาหรับ หรือเบอร์โทร ให้แสดงไอคอนรูปคนแทน ตามที่ Fluent ทำ

## การนำเข้าและใช้งาน

ติดตั้งแพ็กเกจ แล้วนำเข้า stylesheet **ครั้งเดียว** ที่ root ของแอป เช่น ใน `app/layout.tsx`

```bash
npm install lab-package
```

```tsx
import "lab-package/styles.css"
```

จากนั้นนำเข้า component ในไฟล์ที่ใช้

```tsx
import {
  Avatar,
  AvatarBadge,
  AvatarFallback,
  AvatarGroup,
  AvatarGroupCount,
  AvatarImage,
} from "lab-package"

<Avatar role="img" aria-label="Ana Lima">
  <AvatarImage src="/people/ana.jpg" alt="" />
  <AvatarFallback aria-hidden>AL</AvatarFallback>
</Avatar>
```

- นำเข้าเฉพาะส่วนที่ใช้
- Avatar มี `"use client"` มาในตัว จึงใช้จาก Server Component ได้

## ทำให้โปรแกรมอ่านหน้าจอเข้าใจ

เลือกหนึ่งในสองกรณี

- **มีชื่อแสดงอยู่ข้าง ๆ:** avatar เป็นการตกแต่ง ใส่ `alt=""` ที่รูป และ `aria-hidden` ที่ fallback ตาม story `WithName`
- **avatar อยู่เดี่ยว ๆ:** ตั้งชื่อทั้ง avatar ด้วย `role="img"` และ `aria-label` แล้วซ่อนสิ่งที่อยู่ข้างใน คือ `alt=""` ที่รูป และ `aria-hidden` ที่ fallback แบบที่ Fluent และ Shopify Polaris ทำ โปรแกรมอ่านหน้าจอจะได้ยิน "Ana Lima" ไม่ว่าจะแสดงรูปหรืออักษรย่อ ถ้าใส่ชื่อไว้แค่ใน `alt` ของรูป เมื่อรูปโหลดไม่ได้จะถูกอ่านเป็น "A L"

## Props และ variants

Avatar **ไม่มี prop `variant`** เป็นวงกลมเสมอ มีขอบด้านในจาง ๆ เพื่อไม่ให้รูปสีอ่อนกลืนไปกับหน้าสีอ่อน

### Avatar

| Prop | ค่าเริ่มต้น | ทำอะไร |
| ---- | ----------- | ------ |
| `size` | `md` | `sm` 24px, `md` 32px หรือ `lg` 40px |
| `className` | ไม่มี | ปรับเฉพาะจุด เช่น รูปสี่เหลี่ยมสำหรับบริษัท |

ใช้ `sm` ในรายการที่แน่น `md` ในที่ส่วนใหญ่ และ `lg` เมื่อบุคคลเป็นจุดเด่น เช่น ส่วนหัวของบัญชี อักษรย่อขนาด 12px ที่ `sm` และ 14px ที่ขนาดอื่น

### AvatarImage

รับ `src` และ prop อื่นของ `img` ใช้ `alt=""` ในทั้งสองกรณีข้างต้น Base UI โหลดรูปก่อน และแสดงเมื่อโหลดเสร็จแล้วเท่านั้น

### AvatarFallback

| Prop | ค่าเริ่มต้น | ทำอะไร |
| ---- | ----------- | ------ |
| `delay` | `0` | มิลลิวินาทีที่รอก่อนแสดง fallback หน่วงสั้น ๆ เช่น 600 ช่วยไม่ให้อักษรย่อกะพริบก่อนรูปที่โหลดเร็วจะขึ้น Fluent ตั้งใจแสดงอักษรย่อระหว่างโหลด แหล่งอ้างอิงจึงเห็นต่างกัน |

fallback เป็นวงกลมสีเทากับอักษรย่อสีเทา TODO: ยังไม่มีสีเฉพาะของแต่ละคน Fluent เลือกสีจากชื่อได้ ถ้าเพิ่ม อักษรย่อต้องได้ 4.5:1 บนทุกสี

### AvatarBadge

จุดมุมขวาล่าง: 8px ที่ `sm`, 10px ที่ `md`, 12px ที่ `lg` ใส่ไอคอนเล็กได้ที่ `md` และ `lg` ส่วนที่ `sm` ไอคอนถูกซ่อน

- **ใส่สถานะในชื่อของ avatar** เช่น `aria-label="Dev Patel, verified"` และซ่อน badge ด้วย `aria-hidden` ตาม story `WithBadge`
- **ปัญหาที่ทราบ:** ในโหมดสว่าง จุดสีเขียวมะนาวได้ 1.53:1 เทียบกับวงขาวรอบ ๆ และ 1.39:1 เทียบกับวงกลมอักษรย่อสีเทา ต่ำกว่า 3:1 ที่จุดซึ่งมีความหมายต้องได้ โหมดมืดได้ 10.06:1 TODO: ตัดสินใจสีของ badge
- **ยังไม่ใช่ตัวบอกสถานะออนไลน์** มีสีเดียวและไม่มีรูปทรงต่างกัน จึงแยกออนไลน์ ไม่อยู่ หรือไม่ว่างไม่ได้ Fluent ใช้ไอคอนต่างกันต่อสถานะ สีจึงไม่ใช่สัญญาณเดียว TODO: ตัดสินใจว่าจะเพิ่มสถานะเหล่านี้หรือไม่ ที่ขนาด 32px และเล็กกว่า Fluent เตือนว่า badge มองเห็นยาก จึงควรแสดงสถานะเป็นข้อความใกล้ ๆ ด้วย

### AvatarGroup และ AvatarGroupCount

avatar ซ้อนกัน 8px แต่ละอันมีวง 2px สีเดียวกับพื้นหน้า วงกลมจำนวนมีขนาดเท่ากับ avatar ในกลุ่ม

- **แสดงไม่เกินห้าคน** แล้วตามด้วย "+N" Atlassian และ Fluent หยุดที่ห้า GitHub Primer ที่สี่
- **ตั้งชื่อกลุ่ม** เช่น `role="group" aria-label="People on this account"` แต่ละกลุ่มในหน้าต้องมีชื่อของตัวเอง
- **บอกชื่อคนที่ซ่อนอยู่ในตัวนับ** เช่น `aria-label="and 3 more: Dev Patel, Emi Sato, Finn Murphy"` ตาม story `Group`
- TODO: ตัวนับยังไม่ใช่ปุ่ม Fluent ให้ "+N" เปิดรายชื่อทุกคน ส่วน Atlassian แสดงชื่อเมื่อชี้ ตัดสินใจว่าจะเพิ่มหรือไม่

### Avatar ที่กดได้

avatar โฟกัสหรือคลิกไม่ได้ในตัว ถ้าต้องการลิงก์ไปโปรไฟล์ ให้ครอบด้วยลิงก์หรือ Button ที่มีชื่อ ซึ่งต้องมีวงโฟกัสที่มองเห็น และพื้นที่กดอย่างน้อย 24 × 24px avatar ที่ซ้อนกันในกลุ่มชิดกันเกินกว่าจะเป็นปุ่มแยกกันได้ อย่าใส่ tooltip ที่แสดงเฉพาะเมื่อชี้ให้ avatar ธรรมดา เพราะผู้ใช้คีย์บอร์ดและโปรแกรมอ่านหน้าจอเข้าไม่ถึง

โหมดมืดทำงานอัตโนมัติเมื่อมีคลาส `.dark` บน element ที่ครอบอยู่ ขอบด้านในจาง ๆ เปลี่ยนวิธีผสมสีเพื่อให้ยังมองเห็น

## Tokens ที่ใช้

| Token | ใช้สำหรับ |
| ----- | --------- |
| `--muted` | พื้นของ fallback และวงกลมจำนวน |
| `--muted-foreground` | อักษรย่อและตัวเลขจำนวน |
| `--border` | ขอบด้านในจาง ๆ |
| `--primary` | สีของ badge |
| `--primary-foreground` | ไอคอนบน badge |
| `--background` | วงรอบ badge และรอบ avatar ในกลุ่ม |
