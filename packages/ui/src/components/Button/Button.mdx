# Button

**วัตถุประสงค์:** เริ่มการกระทำบนหน้าปัจจุบัน เช่น บันทึก ยืนยัน เปิด dialog หรือคัดลอก

## ควรใช้เมื่อ

- ผู้ใช้ทำการกระทำบางอย่าง เช่น ส่งฟอร์ม ยืนยันขั้นตอน เปิด dialog คัดลอกค่า
- ปุ่มท้าย dialog เช่น "Cancel" และ "Transfer"
- ปุ่มไอคอนอย่างเดียวในแถบเครื่องมือหรือแถวที่แน่น เช่น "Copy link" ต้องมีชื่อที่โปรแกรมอ่านหน้าจออ่านได้

## ไม่ควรใช้เมื่อ

| แทนที่จะใช้ปุ่มกับ… | ให้ใช้ |
| ------------------- | ------ |
| การไปหน้าอื่น | ลิงก์ ถ้าต้องหน้าตาเหมือนปุ่ม ดูหัวข้อ "ปุ่มที่ใช้นำทาง" |
| ป้ายสถานะ หมวดหมู่ หรือจำนวน | **Badge** |
| ปุ่มในช่องกรอก เช่น ค้นหา คัดลอก ส่ง | **InputGroupButton** ใน InputGroup |
| ปุ่มยืนยันของ alert dialog | **AlertDialogAction** ซึ่งรองรับการรองานที่ช้าด้วย |
| ปุ่ม `primary` ตัวที่สองในพื้นที่เดียวกัน | `secondary`, `outline` หรือ `ghost` |
| ลิงก์นำทางในเนื้อความ | ลิงก์ข้อความธรรมดา TODO: ยังไม่มี component Link |

## การเขียนข้อความบนปุ่ม

- **ขึ้นต้นด้วยคำกริยา** และใส่สิ่งที่ถูกกระทำเมื่อบริบทไม่ชัด เช่น "Save changes", "Delete folder", "Copy link"
- **เจาะจง** หลีกเลี่ยง "OK", "Yes", "Submit", "Click here"
- **ตัวพิมพ์แบบประโยค** สั้น ไม่มีเครื่องหมายวรรคตอนท้าย ระบบส่วนใหญ่เห็นตรงกัน แต่ Apple ใช้ตัวพิมพ์ใหญ่ทุกคำ
- **สั้น ๆ ไม่กี่คำ** ปุ่มไม่ตัดบรรทัด ข้อความยาวจะทำให้ปุ่มกว้างขึ้น

## การนำเข้าและใช้งาน

ติดตั้งแพ็กเกจ แล้วนำเข้า stylesheet **ครั้งเดียว** ที่ root ของแอป เช่น ใน `app/layout.tsx`

```bash
npm install lab-package
```

```tsx
import "lab-package/styles.css"
```

จากนั้นนำเข้า component ในไฟล์ที่ใช้

```tsx
import { Button } from "lab-package"

<Button type="submit">Save changes</Button>
```

- Button ไม่มี `"use client"` ในตัว ใน Next.js ไฟล์ที่ส่งฟังก์ชัน เช่น `onClick` ต้องขึ้นต้นด้วย `"use client"` ปุ่มส่งในฟอร์มไม่ต้องมี handler จึงใช้ใน Server Component ได้

## Props และ variants

### `variant` ระดับความเด่น (ค่าเริ่มต้น `primary`)

เรียงจากเด่นที่สุดไปน้อยที่สุด

| Variant | ใช้สำหรับ | หน้าตา |
| ------- | --------- | ------ |
| `primary` | การกระทำหลักในหน้าหรือพื้นที่นั้น **หนึ่งปุ่มต่อพื้นที่** | พื้นเขียวมะนาวทึบ ตัวอักษรเขียวเข้ม |
| `secondary` | การกระทำรองข้างปุ่ม primary | พื้นเทาอ่อนทึบ ตัวอักษรเข้ม |
| `outline` | การกระทำกลาง ๆ เช่น "Cancel" หรือแถบเครื่องมือ | พื้นจางมีเส้นขอบบาง |
| `ghost` | การกระทำที่ไม่ต้องเด่น และปุ่มไอคอนในพื้นที่แน่น | ไม่มีพื้นจนกว่าจะชี้ |
| `link` | การกระทำที่อยู่ในเนื้อความและควรดูเหมือนลิงก์ | ตัวอักษรเขียว ไม่มีพื้น ขีดเส้นใต้เมื่อชี้ |
| `danger` | การกระทำที่ย้อนกลับยาก เช่น ลบ เพิกถอน นำออก | พื้นแดงอ่อน ตัวอักษรแดง |

ลำดับนี้ตรงกับ Material, IBM Carbon, Atlassian และ GitHub Primer: `ghost` คือปุ่ม ghost, invisible หรือ subtle ของระบบเหล่านั้น และ `secondary` คือปุ่ม tonal ของ Material

- **`danger`** เป็นสีแดงอ่อน ไม่ใช่พื้นแดงทึบ หลายระบบใช้แดงทึบกับปุ่ม "Delete" ขั้นสุดท้าย TODO: ตัดสินใจว่าต้องมีแบบแดงทึบหรือไม่ ใช้ `danger` เฉพาะการกระทำที่ย้อนกลับยาก และข้อความบนปุ่มต้องบอกว่าจะลบอะไร เพื่อไม่ให้ความหมายขึ้นอยู่กับการเห็นสีแดงอย่างเดียว
- **`link`** ใช้กับการกระทำที่ควรดูเหมือนข้อความในบรรทัด ถ้าเป็นการไปหน้าอื่นให้ใช้ลิงก์จริง

### `size` ความสูง (ค่าเริ่มต้น `md`)

| Size | ความสูง | ตัวอักษร | ไอคอน | ใช้สำหรับ |
| ---- | ------- | -------- | ----- | --------- |
| `xs` | 24px | 12px | 12px | UI แน่นบนเดสก์ท็อปเท่านั้น เช่น แถวตาราง แถบเครื่องมือ |
| `sm` | 32px | 14px | 16px | พื้นที่กระชับ |
| `md` | 36px | 14px | 16px | ปุ่มส่วนใหญ่ |
| `lg` | 40px | 14px | 16px | การกระทำที่ต้องการให้เด่น |

ทุกขนาดใช้น้ำหนักตัวอักษร medium (500) และมุมโค้งเต็มรูปแคปซูล

**พื้นที่กด:** ขั้นต่ำของ WCAG คือ 24 × 24px ขนาด `xs` จึงผ่านพอดีไม่มีเผื่อ ให้เว้นระยะระหว่างปุ่ม `xs` Apple (44pt) และ Android (48dp) ต้องการพื้นที่กดที่ใหญ่กว่า บนหน้าจอสัมผัสจึงควรใช้ `md` หรือ `lg` ปุ่มในกลุ่มเดียวกันควรมีขนาดเท่ากัน

### Props อื่น ๆ

| Prop | ค่าเริ่มต้น | ทำอะไร |
| ---- | ----------- | ------ |
| `iconOnly` | `false` | ปุ่มสี่เหลี่ยมจัตุรัสสำหรับไอคอนเดียว สูงเท่ากับ `size` **ต้องใส่ `aria-label` เสมอ** |
| `type` | `button` | ใส่ `type="submit"` กับปุ่มส่งฟอร์ม ค่าเริ่มต้นจะไม่ส่งฟอร์มโดยไม่ตั้งใจ |
| `disabled` | `false` | ทำให้จางลง 50% และกดไม่ได้ ดูหัวข้อ "ปุ่มที่ปิดใช้งาน" |
| `focusableWhenDisabled` | `false` | ให้ปุ่มที่ปิดใช้งานยังเข้าถึงได้ด้วยคีย์บอร์ด ผู้ใช้จึงหาเจอและรู้ว่าทำไมใช้ไม่ได้ |
| `render` | ไม่มี | แสดงปุ่มเป็น element อื่น เช่น ลิงก์ โดยหน้าตาเหมือนเดิม |
| `nativeButton` | `true` | ตั้งเป็น `false` ทุกครั้งที่ `render` ไม่ใช่ `<button>` |
| `className` | ไม่มี | ปรับ layout เฉพาะจุด เช่น กว้างเต็ม ควรใช้ variant มากกว่าการเปลี่ยนสไตล์ |

attribute ปกติของปุ่ม เช่น `onClick` และ `aria-*` ใช้ได้ทั้งหมด

**ปุ่มไอคอนอย่างเดียว:** `aria-label` ต้องบอกการกระทำ เช่น "Copy link" ไม่ใช่ชื่อไอคอน เช่น "Copy icon" TODO: IBM Carbon กำหนดให้มี tooltip กับปุ่มไอคอนอย่างเดียว แต่ยังไม่มี component tooltip **ปุ่มที่มีทั้งไอคอนและข้อความ:** ไม่ต้องใส่ `aria-label` เพราะข้อความที่มองเห็นคือชื่อของปุ่มอยู่แล้ว

**กว้างเต็ม:** ยังไม่มี prop ให้ใช้ `className` เช่น ปุ่มในฟอร์มเข้าสู่ระบบบนมือถือ TODO: ตัดสินใจว่าจะทำเป็น prop หรือไม่

**สถานะกำลังโหลด:** Button ยังไม่มี prop สำหรับโหลด TODO: IBM Carbon, Shopify Polaris, Atlassian และ GitHub Primer มีทั้งหมด ตอนนี้มีเฉพาะ AlertDialogAction ระหว่างนี้ให้แอปป้องกันการกดส่งซ้ำเอง

### ปุ่มที่ใช้นำทาง

ปุ่มใช้ทำบางอย่าง ลิงก์ใช้ไปที่อื่น ถ้าลิงก์ต้องหน้าตาเหมือนปุ่ม เช่น "Get started" ให้ใช้ `render` กับลิงก์จริงและ `nativeButton={false}` ลิงก์จะยังเป็นลิงก์สำหรับคีย์บอร์ดและโปรแกรมอ่านหน้าจอ อย่าใช้ลิงก์แบบนี้เปิด dialog

### ปุ่มที่ปิดใช้งาน

หลีกเลี่ยงการปิดใช้งานปุ่ม โดยเฉพาะปุ่มส่งฟอร์ม Atlassian, GitHub Primer และ GOV.UK แนะนำให้ปุ่มกดได้เสมอ แล้วแสดงว่าผิดตรงไหนเมื่อกด ถ้าจำเป็นต้องปิด ให้บอกเหตุผลเป็นข้อความที่มองเห็นได้ใกล้ ๆ และใช้ `focusableWhenDisabled` ให้ผู้ใช้คีย์บอร์ดยังเข้าถึงได้

### การวางตำแหน่ง

- **ใน dialog** การกระทำหลักอยู่ท้ายสุดทางขวา ส่วนท้ายของ Dialog และ AlertDialog จัดให้อัตโนมัติ
- **เมื่อเรียงซ้อนแนวตั้ง** การกระทำหลักอยู่บนสุด
- TODO: **บนหน้าเต็มและฟอร์ม** IBM Carbon, GOV.UK และ Microsoft Fluent วางการกระทำหลักไว้ก่อนทางซ้าย ต้องตัดสินใจกฎของผลิตภัณฑ์
- กลุ่มหนึ่งไม่ควรเกินสองหรือสามปุ่ม ที่เหลือใส่ในเมนู

### สถานะ

| สถานะ | เกิดเมื่อ | หน้าตา |
| ----- | --------- | ------ |
| Hover | ชี้เมาส์บนปุ่ม | พื้นเข้มหรือสว่างขึ้นเล็กน้อย `link` ขีดเส้นใต้ |
| Focus | โฟกัสด้วยคีย์บอร์ดเท่านั้น | เส้นขอบสีโฟกัสและวงจาง 3px |
| Pressed | ระหว่างกด | เลื่อนลง 1px ปุ่มที่เปิดเมนูจะไม่เลื่อน |
| Disabled | `disabled` | จาง 50% กดไม่ได้ |
| Invalid | `aria-invalid` | ขอบแดงและวงแดงจาง |
| Expanded | `aria-expanded` | `outline` และ `ghost` มีพื้นจางขณะเมนูหรือแผงที่ควบคุมเปิดอยู่ `secondary` คงหน้าตาเดิม |

โหมดมืดทำงานอัตโนมัติเมื่อมีคลาส `.dark` บน element ที่ครอบอยู่ แต่ละ variant มีสีโหมดมืดของตัวเอง

**ความต่างของสีของเส้นโฟกัส** WCAG กำหนดอย่างน้อย 3:1 กับสีข้างเคียง เส้นขอบโฟกัสทึบผ่านเกณฑ์

| เส้นขอบโฟกัสเทียบกับ… | สว่าง | มืด |
| --------------------- | ----- | --- |
| หน้า | 5.25 | 4.60 |
| พื้น `primary` | 3.42 | 2.18 |
| พื้น `secondary` | 4.77 | 3.50 |

วงจาง 3px รอบเส้นขอบโปร่งแสง 50% เป็นแค่การตกแต่ง และต่ำกว่า 3:1

### ความต่างของสีตัวอักษร

ตัวอักษร 12px และ 14px ต้องได้ 4.5:1 ทุก variant ผ่านทั้งตอนปกติและตอนชี้

| Variant | สว่าง | สว่าง (ชี้) | มืด | มืด (ชี้) |
| ------- | ----- | ----------- | --- | --------- |
| `primary` | 5.72 | 6.15 | 4.50 | 4.95 |
| `secondary` | 16.12 | — | 14.27 | — |
| `outline` | 18.43 | 17.63 | 17.34 | 16.13 |
| `ghost` | 19.59 | 17.76 | 18.90 | 16.53 |
| `danger` | 5.92 | 4.87 | 5.19 | 4.74 |
| `link` | 5.69 | ขีดเส้นใต้ | 10.06 | ขีดเส้นใต้ |

`primary` ในโหมดมืดตอนปกติผ่านพอดีไม่มีเผื่อ การเปลี่ยน `--primary` หรือ `--primary-foreground` ในโหมดมืดอาจทำให้ต่ำกว่า 4.5:1

## Tokens ที่ใช้

| Token | ใช้สำหรับ |
| ----- | --------- |
| `--primary` | พื้น `primary` และตอนชี้ |
| `--primary-foreground` | ตัวอักษร `primary` |
| `--secondary` | พื้น `secondary` และตอนชี้ |
| `--secondary-foreground` | ตัวอักษร `secondary` |
| `--foreground` | ตัวอักษร `outline` และ `ghost` และผสมในสีตอนชี้ของ `secondary` และ `primary` โหมดมืด |
| `--input` | พื้น `outline` และตอนชี้ |
| `--border` | ขอบ `outline` |
| `--muted` | ตอนชี้ของ `ghost` และพื้นตอน expanded ของ `outline` และ `ghost` |
| `--destructive` | ตัวอักษรและพื้นจางของ `danger` และขอบกับวงตอน invalid |
| `--link` | ตัวอักษร `link` |
| `--ring` | เส้นขอบโฟกัสและวงโฟกัส |
| `--radius` | ความโค้งมุม: 2.6 × `--radius` เป็นแคปซูลทุกขนาด |

ทุก token มีค่าทั้งโหมดสว่างและโหมดมืดใน stylesheet ถ้าต้องการเปลี่ยนปุ่มทั้งระบบ ให้เปลี่ยน token แทนการแก้ทีละปุ่ม
