# lab-package design system

ชุด component สำหรับแอป React / Next.js สร้างจาก shadcn/ui บน Base UI จัดสไตล์ด้วย design token ชุดเดียวกันทั้งระบบ รองรับทั้งโหมดสว่างและโหมดมืด

หน้านี้และหน้า **คู่มือการใช้งาน** ของแต่ละ component เขียนสำหรับนักออกแบบและ AI agent ที่สร้าง UI บอกว่าควรใช้ component ไหนเมื่อไร มี props และ variants อะไรบ้าง และใช้ token ใด ส่วนไหนที่ยังไม่ได้ตัดสินใจจะเขียนว่า **TODO**

## เริ่มใช้งาน

```bash
npm install lab-package
```

นำเข้า stylesheet ครั้งเดียวที่ root ของแอป แล้วนำเข้า component ที่ต้องการ

```tsx
import "lab-package/styles.css"
import { Button } from "lab-package"
```

แอปต้องเตรียมสิ่งเหล่านี้เอง

- **CSS reset** เช่น preflight ของ Tailwind v4
- **คลาส `.dark`** บน element ที่ครอบหน้า (มักเป็น `<html>`) เมื่อต้องการโหมดมืด
- **`--font-heading`** ฟอนต์ของหัวข้อใน Dialog, AlertDialog และ Card
- **`recharts` 3** ถ้าใช้ Chart ให้ติดตั้งเพิ่มด้วย `npm install recharts`
- **`@tanstack/react-table` 8** ถ้าทำตารางข้อมูลแบบเรียงลำดับ กรอง เลือกแถว และแบ่งหน้า ตามสูตรในคู่มือ Table ให้ติดตั้งเพิ่มในแอปของคุณ แพ็กเกจเองไม่ได้พึ่งพามัน

## Components

| Component | ใช้สำหรับ |
| --------- | --------- |
| **Accordion** | แสดงหัวข้อเป็นรายการ คลิกเพื่อเปิดดูรายละเอียดทีละส่วน เช่น คำถามที่พบบ่อย |
| **Button** | เริ่มการกระทำบนหน้านี้ เช่น บันทึก ยืนยัน เปิด dialog |
| **Attachment** | การ์ดแสดงไฟล์แนบหนึ่งไฟล์ พร้อมชื่อ ขนาด สถานะการอัปโหลด และปุ่มลบหรือลองใหม่ |
| **Avatar** | รูปโปรไฟล์ของบุคคล หรืออักษรย่อชื่อเมื่อไม่มีรูป และกลุ่มรูปซ้อนกัน |
| **Badge** | ป้ายเล็กบอกสถานะหรือหมวดหมู่ อ่านอย่างเดียว ไม่ใช่ปุ่ม |
| **Input** | ช่องกรอกข้อความบรรทัดเดียว |
| **Textarea** | ช่องกรอกข้อความหลายบรรทัด |
| **InputGroup** | ช่องกรอกที่มีไอคอน ข้อความคงที่ หรือปุ่มเล็กติดอยู่ในกรอบ |
| **InputOTP** | ช่องกรอกรหัสครั้งเดียว แสดงทีละช่องต่อตัวอักษร |
| **Card** | กล่องที่รวมเนื้อหาและการกระทำเกี่ยวกับเรื่องเดียว เช่น สรุปบัญชี |
| **Chart** | กราฟแท่ง เส้น และพื้นที่ สร้างจาก Recharts พร้อม tooltip และคำอธิบายสี |
| **Checkbox** | ช่องติ๊กเพื่อเปิดหรือปิดตัวเลือกหนึ่งตัว หรือเลือกหลายตัวจากรายการ |
| **Table** | ตารางข้อมูลที่มีหัวคอลัมน์ คำอธิบายตาราง และแถวสรุป พร้อมสูตรตารางข้อมูลที่เรียงลำดับ กรอง เลือกแถว และแบ่งหน้าได้ |
| **Dialog** | หน้าต่างซ้อนสำหรับงานสั้น ๆ หนึ่งงาน เช่น ฟอร์มเล็ก |
| **AlertDialog** | หน้าต่างยืนยันก่อนทำสิ่งที่ย้อนกลับไม่ได้ |

เปิดหัวข้อ **คู่มือการใช้งาน** ใต้ชื่อ component ในแถบด้านซ้ายเพื่ออ่านแนวทางแบบเต็ม หัวข้อ **Docs** คือตาราง props ที่สร้างจากโค้ดอัตโนมัติ

## คำศัพท์ที่ใช้ร่วมกัน

ทุก component ใช้ชื่อ prop ชุดเดียวกัน

- **`variant`** ระดับความเด่น: `primary`, `secondary`, `outline`, `ghost`, `danger`, `link` (ค่าเริ่มต้น `primary`)
- **`size`** ขนาด: `xs`, `sm`, `md`, `lg` (ค่าเริ่มต้น `md`) และ `iconOnly` สำหรับปุ่มไอคอนอย่างเดียว
- **`invalid`** สถานะผิดพลาดของช่องกรอก ทำให้ขอบเป็นสีแดงและบอกโปรแกรมอ่านหน้าจอว่ามีข้อผิดพลาด

## หลักการด้านการเข้าถึง (accessibility)

ทุก component ตรวจตาม WCAG 2.2 ระดับ AA

- **ข้อความ** มีความต่างของสีกับพื้นหลังอย่างน้อย 4.5:1
- **เส้นขอบโฟกัส** ต่างจากสีข้างเคียงอย่างน้อย 3:1 และเห็นได้เมื่อใช้คีย์บอร์ด
- **พื้นที่กด** อย่างน้อย 24 × 24px
- **สีไม่ใช่สัญญาณเดียว** ข้อผิดพลาดและสถานะต้องมีข้อความกำกับเสมอ
- **ช่องกรอกทุกช่องต้องมี label** มองเห็นได้ หรือใช้ `aria-label` เมื่อไม่มีที่วาง

## Token หลัก

สีและขนาดทั้งหมดมาจาก CSS variables ใน `lab-package/styles.css` แต่ละตัวมีค่าทั้งโหมดสว่างและโหมดมืด เปลี่ยน token เพื่อเปลี่ยนทั้งระบบ แทนการแก้ทีละ component

| Token | ใช้สำหรับ |
| ----- | --------- |
| `--primary`, `--primary-foreground` | สีหลักของแบรนด์ (เขียวมะนาว) และข้อความบนสีนั้น |
| `--secondary`, `--secondary-foreground` | พื้นสีเทาอ่อนและข้อความบนพื้นนั้น |
| `--foreground`, `--background` | ข้อความและพื้นหลังของหน้า |
| `--muted`, `--muted-foreground` | พื้นที่จาง และข้อความรอง เช่น placeholder |
| `--destructive` | สีแดงสำหรับการลบและข้อผิดพลาด |
| `--link` | ข้อความลิงก์ |
| `--input`, `--border` | ขอบและพื้นของช่องกรอก |
| `--ring` | เส้นขอบโฟกัส |
| `--popover`, `--popover-foreground` | พื้นและข้อความของ Dialog |
| `--radius` | ความโค้งของมุม |
